what changed

1Role badge is the pin control. The per-row "auto" select is gone. The badge always states the engine's decision; clicking it opens a menu (auto · primary · accent · …). A pinned badge gets a ⌖ glyph and an outline — state you can see at a glance. "↺ reset pins" only appears when a pin exists: that's the "auto all at once" button, shown only when it can do something.

2Fidelity promoted, wording settled: smith's taste ↔ raw colors. Bigger two-tone track (cool = engine, warm = yours). The live caption does the real explaining: on an in-window preset it reads "your colors already sit well — nothing to tune"; at 1.0, "colors kept exactly · 1 clash reported".

3Mockup lives in the frame row. Not just moved up — each frame row owns its mockup select, mode toggle, copy, close. Direct manipulation: no "select the frame, then scroll down to change its mockup".

4One start card, three routes. Hex typing and the picker merge into a single field — the embedded swatch previews what you typed and opens the picker (eyedropper moves inside the popover). Image drop and preset sit in the same inset card, so "the ways in" read as one unit.

5 · No section labels. Dividers group; components self-describe (placeholder text, live caption, badges, option labels).

6The report is no longer a "view". The preview/report pill is gone. The audit becomes an always-visible status chip under the fidelity slider — the answer to "can I trust this?" without a mode flip. Clicking it slides the report in as a drawer over the canvas, so a failing pair sits next to the live mockup instead of replacing it. The CSS textarea stops being a destination; code leaves via export only.

7Export is one split button. Copies the last-used format on click; the ▾ menu swaps format. Scales to "Download .css" later without new rows.
