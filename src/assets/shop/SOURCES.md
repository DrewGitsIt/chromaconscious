# Image sources (homewares shop)

Every image here is public domain; each entry quotes the licence as the source states it. Files are renamed from the names in the heading. All are from The Metropolitan Museum of Art and were photographed on the museum's grey seamless sweep. All were resized to a 1600px long edge and re-encoded as JPEG.

### teapot.jpg (1600×1600), was DP-18258-025.jpg
- **Title:** Teapot. Christopher Dresser, ca. 1879. Silverplate, ebony. Accession 2021.153.2
- **Creator / institution:** The Metropolitan Museum of Art (Gift of Lawrence A. and Janet Y. Larose, 2021)
- **Source page:** https://www.metmuseum.org/art/collection/search/823191
- **Download URL:** https://images.metmuseum.org/CRDImages/es/original/DP-18258-025.jpg
- **License:** The Met Collection API object record has `"isPublicDomain": true`, which marks it as Public Domain / Open Access under The Met's CC0 policy.
- **Two-tone note:** Strong. A polished hemispherical body with a diagonal black ebony handle sits on a graded grey sweep. The handle gives a solid dark accent, and the mirror-bright metal gives the lightest highlights. The object fills about 60% of the width. Square crop as is for the hero.

### teapot-back.jpg (1600×1600), was DP-18258-026.jpg
- **Title:** Teapot (same object as teapot.jpg, reverse three-quarter view)
- **Creator / institution:** The Metropolitan Museum of Art
- **Source page:** https://www.metmuseum.org/art/collection/search/823191
- **Download URL:** https://images.metmuseum.org/CRDImages/es/original/DP-18258-026.jpg
- **License:** Same object record: `"isPublicDomain": true`.
- **Two-tone note:** Strong, and it matches the hero's lighting and background, so it works as a gallery thumbnail. The arched handle reads as a clean loop. *Note:* the Met's third image of this object (DP-18258-046) is a close-up of the maker's stamped marks and was skipped on purpose.

### sugar-bowl.jpg (1600×1600), was DP-22473-061.jpg
- **Title:** Sugar bowl (Model 247). Christopher Dresser, ca. 1885. Silver-plated nickel. Accession 2021.7.2
- **Creator / institution:** The Metropolitan Museum of Art (Gift of Jacqueline Loewe Fowler, 2020)
- **Source page:** https://www.metmuseum.org/art/collection/search/751987
- **Download URL:** https://images.metmuseum.org/CRDImages/es/original/DP-22473-061.jpg
- **License:** The Met Collection API object record has `"isPublicDomain": true`.
- **Two-tone note:** Strong. An inverted silver cone stands on three bent legs on a grey sweep, giving a very graphic silhouette. It is the same material and lighting as the teapot. Square crop as is.

### vase.jpg (1244×1600), was DP-1687-027.jpg
- **Title:** Bottle vase. Christopher Dresser, ca. 1882. Glazed earthenware. Accession 2016.178.3
- **Creator / institution:** The Metropolitan Museum of Art (Gift of Florence and Herbert Irving, 2016)
- **Source page:** https://www.metmuseum.org/art/collection/search/670806
- **Download URL:** https://images.metmuseum.org/CRDImages/es/original/DP-1687-027.jpg
- **License:** The Met Collection API object record has `"isPublicDomain": true`.
- **Two-tone note:** Good. A dark bottle-shaped vase with a pinched body stands on a light sweep, so the outline is clear. The crackled glaze turns into a fine light-on-dark web, which is busier than the other three. The vase fills only about 40% of the frame, so crop tighter, to the middle three-fifths, to match the others' scale.
